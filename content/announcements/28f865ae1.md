# Abstract

Lattice gauge theories are a fundamental tool in theoretical physics, originally conceived within the theory of strong interactions, which has found applications in multiple fields since. I will present an unconventional, self-contained introduction to lattice gauge theories in the Hamiltonian formulation, utilizing tools from statistical mechanics, and then discuss the framework application to quantum simulation, utilizing epitome theories.

This talk is part of the series "Probability, Statistical Mechanics and Quantum Fields". The program can be found here:
