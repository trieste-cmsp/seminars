# Abstract

In this talk I will discuss the task of charting phase diagrams of perturbed conformal field theories (CFT). I will explain how massive perturbations can be labelled by conformal boundary conditions in the UV CFT. I will then describe how the phase diagrams of perturbed 2D CFTs can be   found numerically via truncated Hamiltonians and the attempts to describe them analytically using variational ansatze based on conformal boundary conditions. Various challenges for the analytic description will be discussed.
